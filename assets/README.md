这些文件随仓库分发，克隆下来即可使用。**权利状态见上一级 `NOTICE.md`**：属于《绝区零》美术素材，版权归原权利人，**仅限非商业使用**，不在 MIT 许可范围内。

## 现有文件

| 文件 | 用途 | 谁在用 |
| --- | --- | --- |
| `boot.mp4` | 冷启动开机影片 | 新会话页 / 首屏 |
| `poster.jpg` | 影片封面（未播放时的静帧） | 同上 |
| `backdrop.png` | 新会话页整屏背景 | 同上 |
| `chat-bg.jpg` | 对话区默认背景（面板选「跟随皮肤」时用它） | 对话区 |
| `icon-512.png` | 应用图标（大） | `/hdd/v1/icon.png` |
| `icon-64.png` | 应用图标（小） | 拾取器、缩略图 |
| `app.ico` | Windows 窗口图标 | `/hdd/v1/app.ico` |
| `icon-256.png`、`tray.ico` | 备用图标，当前路由未使用 | —— |

## 换成自己的素材

文件名不变，逐项替换即可，代码里没有对画面内容的依赖：

- 影片：任意 1920×1080 的 mp4（H.264），或一张 1 秒静帧短片；
- 背景：任意 jpg / png；
- 图标：512×512 与 64×64 方图；`.ico` 可用 ImageMagick 转：
  `magick icon-512.png -define icon:auto-resize=256,64,48,32,16 app.ico`

换完跑一次校验：

```bash
npm run check:assets
```

它只看文件是否存在、是否非空，不判断画面对不对。
